

# 🚀 Desafios e Exercícios com APIs em JavaScript

Bem-vindo ao repositório de **Exercícios de APIs**! Aqui você encontrará uma série de desafios para praticar o consumo de APIs com **JavaScript**. Vamos aprimorar suas habilidades e aprender a trabalhar com dados externos de maneira divertida! 🌟

## 📜 Exercícios

### 1. 📚 **Obter Dados de uma API de Livros**
Crie um aplicativo simples que consome uma API de livros, como a [Open Library](https://openlibrary.org/developers). O desafio é buscar livros por título ou autor e exibir uma lista com informações como título, autor e imagem da capa. 📖

#### 🛠️ Desafio:
- Use `fetch()` ou `axios` para fazer a requisição à API.
- Exiba o nome do livro, autor e a capa do livro.
- Crie um campo de busca para filtrar os resultados por título ou autor.

---

### 2. 🌤️ **Clima em Tempo Real**
Consuma a API [OpenWeather](https://openweathermap.org/api) e crie uma aplicação que mostre as condições climáticas atuais de uma cidade. ☀️🌧️

#### 🛠️ Desafio:
- Busque o clima de uma cidade utilizando a API de previsão.
- Exiba informações como temperatura, descrição (ex: ensolarado, chuvoso) e ícone do clima.
- Permita ao usuário digitar o nome da cidade para buscar o clima.

---

### 3. 📝 **To-Do List com API**
Crie uma **To-Do List** utilizando uma API fake, como a [JSONPlaceholder](https://jsonplaceholder.typicode.com/), para criar, listar e deletar tarefas. ✅❌

#### 🛠️ Desafio:
- Utilize `GET` para listar as tarefas.
- Utilize `POST` para adicionar novas tarefas.
- Utilize `DELETE` para remover tarefas.
- Exiba as tarefas em uma lista dinâmica com opções de marcar como concluída ou remover.

---

### 4. 🎮 **Jogo de Trivia**
Consuma a [Open Trivia Database](https://opentdb.com/) e crie um jogo de trivia com perguntas e respostas. 🧠

#### 🛠️ Desafio:
- Busque perguntas de múltiplas escolhas com a API.
- Exiba a pergunta e as alternativas.
- Permita ao usuário escolher uma resposta e informe se a resposta está correta.
- Mostre a pontuação final no final do jogo.

---

### 5. 🖼️ **Galeria de Imagens com API**
Crie uma galeria de imagens utilizando a API [Unsplash](https://unsplash.com/developers). 🖼️

#### 🛠️ Desafio:
- Consuma a API para buscar imagens de uma categoria específica (como natureza, arquitetura, etc.).
- Exiba as imagens em uma galeria com um título e autor.
- Permita que o usuário busque por novas imagens inserindo palavras-chave.

---

### 6. 🚶‍♂️ **Localização e Mapa**
Use a [Geolocation API](https://developer.mozilla.org/en-US/docs/Web/API/Geolocation_API) para obter a localização atual do usuário e mostre um mapa utilizando o [Leaflet.js](https://leafletjs.com/) ou o [Google Maps API](https://developers.google.com/maps). 🗺️

#### 🛠️ Desafio:
- Obtenha a latitude e longitude do usuário.
- Exiba a localização no mapa.
- Permita que o usuário veja o nome do local baseado na sua localização.

---

### 7. 🎧 **API de Música**
Consuma a [Spotify API](https://developer.spotify.com/) para criar um player básico de músicas. 🎶

#### 🛠️ Desafio:
- Crie uma tela para buscar músicas.
- Exiba os resultados com título da música, artista e imagem do álbum.
- Permita ao usuário ouvir a música diretamente na aplicação.

---

### 8. 🕹️ **API de Filmes**
Use a [OMDb API](http://www.omdbapi.com/) para criar um aplicativo que busca informações sobre filmes. 🎬

#### 🛠️ Desafio:
- Faça uma busca por nome de filme.
- Exiba o título, ano, gênero e poster.
- Permita que o usuário veja mais detalhes sobre o filme (sinopse, elenco, etc.).

---

## 📦 Como Executar os Exercícios

1. Clone este repositório:
    ```bash
    git clone 
    cd api-exercicios
    ```

2. Instale as dependências:
    ```bash
    npm install
    ```

3. Abra o arquivo HTML e inicie o seu servidor:
    ```bash
    live-server
    ```
